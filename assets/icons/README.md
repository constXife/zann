# Product icons

The shared Zann icons used by COSMIC packaging and local installation live
here, outside client shells. These PNGs were moved byte-for-byte from the
retired application; no image content changed.

Sizes: `32x32.png`, `64x64.png`, `128x128.png`, `128x128@2x.png` (256 px),
and `icon.png` (512 px).
